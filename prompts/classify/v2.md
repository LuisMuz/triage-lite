<severity_steps>
Decide severity with these steps, in order, and stop at the first that fits:
1. critical: data loss, a payment failure, a security exposure, or a core flow down for everyone, with no workaround.
2. high: a core flow (login, cart, checkout, payments, search) is broken or wrong for many users. Only these five flows can be high without data loss or a security exposure; a feature outside them is at most medium, even when it is completely broken.
3. medium: a feature outside the core flows is broken or shows wrong values, or a core flow fails only for a small group of users or in one environment.
4. low: nothing is blocked and the values are right: cosmetic, layout, copy, image quality or minor usability.

Boundary examples (not from this batch):
- "Card payments fail for everyone, PayPal still works": high, not critical, because a workaround exists.
- "Wishlist button does nothing for every user": medium, not high, because the wishlist is not a core flow.
- "Order history shows the wrong delivery date": medium, not low, because a value is wrong.
- "Shipping costs label is misaligned on small screens": low, not medium, because nothing is blocked or wrong.
